## C. 本番中のトラブル対応

| 状況 | 操作 |
|---|---|
| 音を全部止めたい | **`Esc`** |
| 1 つだけ止めたい | 右側「再生中」欄の **停止** |
| 自然に消したい | **`F`** または **フェードアウト** ボタン |
| BGM だけ止めたい | そのリストの **停止** ボタン |
| 順番を飛ばす | 目的のキューをクリック → そのリストのキー（`Z`/`X`/`C`） |
| 進めすぎた | `←` `→` でそのリストへ移り、**`↑`** で NEXT を 1 つ戻す |
| セリフが聞こえない | BGM リストの**グループ音量**を下げる |
| 音が出ない | ①出力先 ②本体音量 ③ミキサー の順に確認 |
| 曲の頭が欠ける | 画面上部のバッジをクリック（音声出力を起こし直す） |
| アプリが固まった | アプリを閉じて再起動（音源は残っています） |
| 端末が壊れた | 予備機 ＋ USB の `.kasupack` で復元 |
