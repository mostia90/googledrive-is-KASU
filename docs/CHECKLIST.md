## C. 本番中のトラブル対応

| 状況 | 操作 |
|---|---|
| 音を全部止めたい | **`Esc`** |
| 1 つだけ止めたい | 右側「再生中」欄の **停止** |
| 自然に消したい | **`F`** または **フェードアウト** ボタン |
| 順番を飛ばす | 目的のキューをクリック → **`Space`** |
| 進めすぎた | **`↑`** で NEXT を 1 つ戻す |
| 音が出ない | ①出力先 ②本体音量 ③ミキサー の順に確認 |
| アプリが固まった | アプリを閉じて再起動（音源は残っています） |
| 端末が壊れた | 予備機 ＋ USB の `.kasupack` で復元 |
